## Шкала оценки кейса

Заполняется из раздела «Метрики и критерии оценивания» самого ТЗ. **У кейса бывает собственная таблица на 100 баллов, не совпадающая с общей таблицей п. 7.4 Положения** — план работ строится по кейсовой.

|  |  |  |
|  |  |  |

- Тип задачи, ограничения на ИИ и внешние API: `______`
- Формат решения, разрешённый ТЗ: `______`
- **Повышают ли дополнительные возможности максимальный балл:** `______`

> Проверять этот пункт в первую очередь. В ТЗ пробного запуска было прямо: «Эти функции оцениваются только после обязательного сценария и не повышают максимальный балл». Если такая оговорка есть — всё время идёт в обязательный сценарий, надёжность и удобство, а не в бонусы.
