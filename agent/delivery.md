# Воспроизводимость, README и сдача

**Это не баллы, а условие допуска.** По редакции от 22.09.2026 (пп. 5.4.16 и 5.6.5) проект, который не удаётся запустить по инструкциям из репозитория, к дальнейшему отбору не допускается, и «дополнительные пояснения и исправления не принимаются».

## Воспроизводимость

- Свежий клон запускается одной-двумя командами строго по README, без регистрации в сторонних сервисах.
- `.env.example` содержит все переменные с пояснениями. Без необязательных ключей основной сценарий работает, а зависящая от ключа функция честно сообщает, что недоступна.
- Тесты запускаются одной командой, команда указана в README.
- Облачные сервисы — только опция или для развёрнутой версии, никогда не единственный способ запуска.
- **Ключевая функциональность проверяется без наших аккаунтов — это требование, а не совет.** П. 5.6.6: проверка должна быть возможна «без необходимости использования личных аккаунтов участников, персональных подписок или закрытых учетных записей», а при использовании внешних сервисов и API команда обязана предоставить демонстрационные доступы, тестовые учётные записи либо иной способ проверки.
- **Ни одной команды в README, которой не существует.** Каждая команда и каждый упомянутый компонент проверяются исполнением: нет теста без конфига, нет упоминания базы, к которой приложение не подключается.
- Зафиксировать версию среды выполнения, а не надеяться на машину эксперта.

В README описывается только то, что реально работает. Соответствие требованиям формулируется буквально:
«REQ-03 выполнено: реализация — `src/…`, проверка — `…`».

## Перед сдачей

- **Проверка на свежем клоне** в отдельной папке — строго по тексту README, без опоры на текущее окружение.
- **Ревизия связности:** каждый файл в исходниках кем-то импортируется, каждая зависимость в манифесте встречается в коде, каждый нужный для запуска файл реально добавлен в индекс. Один неотслеженный lock-файл убивает единственный документированный способ развёртывания.
- Пять некорректных вводов в основном сценарии — приложение не падает.
- Ни одного секрета в репозитории и в его истории.
